# 04：删管理、关 QoS/UPnP、调防火墙，怎样一项一项做

[返回首页](../README.md)

## 一、改之前，先约定好边界

建议把授权写成这样：

> 只允许处理下面列出的具体项目。先读取当前值和目标对象，再提交，每项提交后独立重读。保留上网拨号、桥接、VLAN、光路身份、LAN 地址和现有远程管理路径。确需扩大范围时先停，不要用“帮我解决”当无限权限。已明确授权的范围连续做完，不重复询问同一件事。

一次可以授权一组明确的改动，但执行时仍然应**改一项，验一项**。

不要同时改桥接、QoS、防火墙、DNS、MTU 和网卡速率，然后靠“现在好像能上网”判断是哪项起作用。

## 二、删除电信的 IP 远程管理连接

### 你到底在删除什么

常见关键词：

- TR069：一套远程管理规范；
- CWMP：相关管理协议名称；
- ACS / ITMS：管理服务器或平台的叫法。

大白话就是：运营商可以通过某条管理通道，给光猫读状态、下发设置。

WAN 列表里可能看到：

```text
1_TR069_VOICE_R_VID_46
2_INTERNET_B_VID_41
3_OTHER_B_VID_43
```

这是浙江样本，不是通用模板。

其中第一条在案例中是**管理加语音**，第二条是上网桥接，第三条是其他业务桥接。

### 删除前必须确认的东西

- [ ] 名称和服务类型确实是目标管理连接；
- [ ] 当前状态和工作模式已读取；
- [ ] VLAN 已读取，但不会被照抄到其他地方；
- [ ] 内部连接编号已读取；
- [ ] 没有选中 INTERNET 上网连接；
- [ ] 是否合并了语音、电视或其他业务已经核对；
- [ ] 用户明确接受相应业务可能受影响；
- [ ] 光猫的本地管理路径仍保留；
- [ ] 不是靠这条唯一通道在远程操作；
- [ ] 失败时怎样恢复已经有可执行方案。

“语音当前注册失败”不是最后一项授权的替代品。用户可能以后还要用。

### 远程操作最大的坑：默认选中的是上网连接

浙江样本里，页面默认选中 INTERNET，内部索引是 `8`。

真正的管理连接内部索引是 `0`。

如果只看到了“删除用编号”，就把默认表单直接发出去，删掉的可能是上网连接。远程站点会立刻断联，未必能自动恢复。

**`0` 不是管理连接的通用编号。** 别因为教程写了这个数，就在你的设备上也删 `0`。

### 正确的执行顺序

1. 打开 WAN 配置页，列出所有现有连接。
2. 在页面中切到目标管理连接。
3. 重新读取这一页，确认显示的名称、类型、VLAN、内部编号相互一致。
4. 读取“删除”按钮真正调用的函数，而不是猜一个请求。
5. 在内存中构造提交内容，只显示不敏感的目标字段供核对。
6. 确认授权仍覆盖这条具体连接，提交一次。
7. 独立重读 WAN 列表。
8. 确认管理条目消失，INTERNET 和其他要保留的业务仍在。
9. 再检查后级路由器的拨号状态和实际外网连通。

### 本样本实际用过的字段

```text
页面：/cgi-bin/net-wanset.asp
Wan_Flag=3
OperatorStyle=Del
curSetIndex=当前已确认的目标连接编号
afterdeleteFlag=删除后要显示的剩余连接编号
```

这只是帮助你读懂当前页面的线索，**不是可直接复制的删除请求**。表单里还有当前对象、校验 Cookie 等内容，固件版本也可能变。

### 删除后可以承诺什么，不能承诺什么

可以说：

> 专用 TR069/VOICE IP 管理 WAN 已删除，当前列表只剩已核对的桥接业务。

不能说：

> 电信从此绝对不可能再管理光猫，超级密码永远不会变。

光路侧的 OMCI、设备重新注册、运营商维护和其他管理路径，不会因为删除一条 IP WAN 就全部消失。也不要为了阻断所有管理去改 PON 身份、LOID、SN 或局端参数。

## 三、关闭光猫 QoS

QoS 可以理解为“给流量排队、分优先级或限制速率”的一类功能。

先分清：

- 光猫 QoS；
- iKuai 或其他路由器 QoS；
- 运营商套餐和局端限速。

关掉第一种，不代表后面两种也没了，更不代表一定能提升速度。

### 这次为什么只改一个勾选框也要看脚本

浙江样本的页面保存前，会根据勾选框重新填隐藏字段，还会计算 `EBOOVALUE` 校验 Cookie。

这个校验值是“表单内容的一致性检查”，不是登录密码，也不是换成随便一个数就行。

做法：

1. 读取当前 QoS 模板和启用状态；
2. 保留队列、权重、限速和模板等原值；
3. 只取消“启用 QoS”；
4. 按当前网页的提交逻辑构造字段和校验；
5. 提交后用新请求重读；
6. 核对勾选框确实取消，再确认上网正常。

如果隐藏字段仍显示另一个值，不要立即挑一个有利的值宣布成功。追页面加载逻辑，记录你验证的是配置状态还是实际转发行为。

## 四、关闭上海样本的光猫 UPnP

UPnP 的一个用途，是让内网应用自动申请端口映射。

注意：

> 光猫 UPnP 和路由器 UPnP 是两处设置。关一个不等于另一个也关了。

如果用户只授权关光猫，不要顺便改路由器，否则游戏、远程访问或其他应用可能受到影响。

中兴样本的页面是 `app_upnp_t.gch`，对应配置字段是：

```text
EnableUPnPIGD=0
```

但写入并不是简单 POST 这一行，固件还使用加密表单和会话校验，见后面的专节。

验收不能只看返回 `SUCC`：重新读取页面，确认值是 `0`。

## 五、把防火墙强度调到最低

这项只在用户明确选择时执行，不是教程对所有家庭的推荐。

### 两台样本的选项不同

| 样本 | 低 | 中 | 高 |
|---|---|---|---|
| 上海中兴 | `Level=1` | `Level=2` | `Level=3` |
| 浙江 ZNXT | `SecurityLevel=low` | `medium` | `high` |

浙江页面还出现过 `FltsecLevel=1` 这个变量，但它不能直接代替实际选中的 `SecurityLevel`。

实际读取 `selected` 后，才确认原来选中的是高档。

### “低档”不等于把所有开关都关掉

页面可能同时还有：

- 防火墙总开关；
- 攻击防护；
- IPv6 状态检查；
- 端口扫描防护。

用户只说“强度最低”，就只选最低档，不要自动把这些独立开关全部关闭。

这次修改的验证方式：

- 上海：`Level` 从 `3` 变成 `1`，其他三个独立字段原样保留；
- 浙江：实际选项从 `high` 变成 `low`，其他控制字段保持不变；
- 两边 iKuai 防护不动；
- 原有本地对时访问限制不动；
- 两边上网和自动校时继续正常。

### 档位大致是什么意思

浙江样本页面把低档描述为常见畸形报文、源地址伪造和泛洪防护，中档增加扫描、SYN 泛洪等，高档再增加 WAN Ping 和异常 ICMP 限制。

这些是**该厂商页面的说明**，不能据此断言另一家设备逐条实现完全相同，也不能断言所有桥接经过的流量都按同一规则处理。

iKuai 仍然是路由侧的互联网防火墙，不能被光猫档位替代。

## 六、中兴样本的表单为什么不能照旧教程直接 POST

本次固件会在提交前做下面的事：

```text
收集当前表单字段和 _SESSION_TOKEN
        |
拼成参数串
        |
生成临时 key 和 iv
        |
参数串用 AES-CBC 加密 -> IF_ENCODEPARAM
        |
key/iv 用页面里的公钥封装 -> IF_ENCODE
        |
最后只提交这两个加密字段
```

大白话：你以为点“保存”发的是几行设置，网页实际先给它们套了两层封套。

如果你的脚本只发明文字段，失败不一定是密码错，更不意味着应该重置光猫。

在这个样本里：

- 公钥来自当前登录后的 `start.ghtml`；
- 每个页面带自己的 `_SESSION_TOKEN`；
- AES 密钥和 IV 按页面函数处理；
- 表单采用当前页面规定的编码和填充；
- 成功后仍须独立重读目标值。

**不要把这段概念说明当成所有中兴固件的统一算法。** 应先读取当前页面的 `handleBeforeSubmit`、`setEncodePara`、`EncodeKey`、`EncodePara` 等实际函数。

## 七、这几种“顺手优化”不要做

- 为了让管理页面好进，关闭整个 iKuai 防火墙；
- 为了校时，重新建立运营商管理通道；
- 为了网页脚本成功，永久固化 Telnet 或写固件；
- 为了少一个报错，把所有未知字段填成 0；
- 为了“统一两边”，照抄 VLAN、MAC、LOID、接口名；
- 为了验证改动，未经授权重启远程站点；
- 某条请求失败，就换成公网地址再提交一次。

## 八、验收用这一小张表就够

| 项目 | 提交前 | 提交后独立读取 | 业务确认 |
|---|---|---|---|
| 目标 WAN | 准确名称、业务和内部编号 | 仅目标消失，保留业务仍在 | 拨号和上网 |
| QoS | 当前模板与勾选状态 | 目标勾选状态改变，其他值未动 | 基础连通，性能效果不乱承诺 |
| UPnP | 开关与映射列表分别读取 | 开关关闭 | 只验证本次授权的影响范围 |
| 防火墙 | 实际选中档位和独立开关 | 最低档，独立开关按原授权保留 | 上网和管理仍正常 |

写不出“提交前是什么、提交后独立读到什么”，就不要写“已完成”。
