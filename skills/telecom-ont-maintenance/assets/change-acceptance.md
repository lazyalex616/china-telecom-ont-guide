# 变更与独立回读验收表

这张表不是授权书本身。先让设备所有者明确批准具体对象和影响，再执行。不要填原始配置或凭据。

## 一次只写一个目标

| 项目 | 记录 |
|---|---|
| 目标设备已在安全通道内核对 | 待确认，不记录唯一标识 |
| 具体模块与对象 | 待填 |
| 修改前的实际值 | 待读 |
| 期望值 | 待确认 |
| 真实提交方法和当前对象 ID | 在执行环境核对，公开报告不贴完整请求 |
| 用户授权范围 | 待记录 |
| 固定电话、电视、上网和管理路径影响 | 待确认 |
| 必须保留的设置 | 待列 |
| 失败恢复条件与现有管理路径 | 待确认 |
| 是否需要扩大授权 | 待确认，需要则先停 |

## 执行与验收

- [ ] 提交前重新读取目标，而不是使用旧缓存。
- [ ] 名称、业务、模式、VLAN、内部编号相互一致，不照抄案例编号。
- [ ] 保留其他字段，不把未知值统一填 0。
- [ ] 只提交已授权的目标改动。
- [ ] 新请求独立回读，不只看返回成功。
- [ ] 保留业务的状态按授权方法核对。
- [ ] 临时访问已关闭并核实，或如实记录尚未确认。
- [ ] 没有凭据、票据、完整请求或原始配置进入报告。

| 验收项 | 提交前 | 提交后独立读取 | 实际验证方法 | 通过 / 未通过 / 未运行 |
|---|---|---|---|---|
| 目标配置 | 待填 | 待读 | 待填 | 未运行 |
| 无关字段保持 | 待填 | 待读 | 语义对照 | 未运行 |
| 保留业务 | 待填 | 待读 | 限于授权范围 | 未运行 |
| 管理与临时入口 | 待填 | 待读 | 设备状态与实际响应 | 未运行 |

## 最终结果

- 完成了什么：待填。
- 没完成什么及实际影响：待填。
- 哪些验证没有运行：待填。
- 后续是否有人工或定时维护：按实际记录，不自动新增。
