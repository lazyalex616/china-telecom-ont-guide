# 只读盘点表：先复制，再填写

不要填写密码、完整宽带账号、SN、LOID、MAC、公网地址、私人域名、Cookie 或 Token。必要身份仅在私密工具中核对，这里记录“已核对”。空白不是“没有”，未知项要写“未确认”。

## 授权与现场

| 项目 | 记录 |
|---|---|
| 本人或授权设备 | 待确认 |
| 当前有效超密已从装维取得 | 待确认，不记录值 |
| 运营商省份、型号、固件 | 待填 |
| 请求位置与目标身份 | 待确认，不公开主机标识 |
| 谁在拨号，桥接还是路由 | 待确认 |
| 现有本地与远程管理路径 | 待确认，仅写结构 |
| 固定电话 / 运营商电视是否使用 | 待确认 |
| 本次允许修改 | 无，只读 |
| 本次实际发生写操作 | 待记录，应为无 |

## 页面与对象覆盖

每条 WAN、每个现有 SSID、每条语音线路和每个分页分别追加一行，不只保留默认选中项。

| 模块 / 页面 | 对象、下拉项或分页 | 当前值与单位 | 依据 | 结果 / 未覆盖原因 |
|---|---|---|---|---|
| 设备 / 光路 | 当前设备 | 待读，不含身份 | 状态与能力 | 未读 |
| WAN | 每条现有连接 | 业务、模式、VLAN、绑定、状态 | 切对象后独立读 | 未读 |
| 远程管理 | 管理服务与共用业务 | 启用、注册、依赖 | 状态与设置 | 未读 |
| LAN / DHCP / IPv6 | 各现有对象 | 待读 | 当前页面 | 未读 |
| 无线 | 硬件与各现有 SSID | 不记录 SSID 和密码 | 能力及实际状态 | 未读 |
| 安全 | 档位及独立开关 | 待读 | selected / checked 与加载逻辑 | 未读 |
| 应用 | NAT / UPnP / DDNS / 组播 | 开关与规则表分别记录 | 当前状态 | 未读 |
| 语音 | 每条现有线路 | 启用、注册、错误原因 | 状态，不含账号 | 未读 |
| 日志 / 维护 | 状态页，不触发动作 | 待读 | 当前设置 | 未读 |
| 时间 | 时区、真实时钟、接口、服务器 | 不含私人地址 | 页面 / HTTP / 进程各标来源 | 未读 |

## 脱敏结论

- 已证实事实：待填。
- 仍未知的项与原因：待填。
- 发现敏感字段：只记录类别和是否存在，不含值。
- 修改建议及业务影响：待填，尚未授权执行。
- 未触发的动作：按实际记录，不把没检查的写成已确认。
