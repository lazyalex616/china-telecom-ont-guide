# 直接复制给 Agent：第一次只读维护

下面是提示词，不包含设备身份或凭据。先按实际情况补充非敏感前提，再交给你已授权的 Agent。

```text
请使用 telecom-ont-maintenance Skill 维护本人或已获明确授权的电信光猫。

前提：向负责这条宽带的装维师傅取得当前有效的超级管理员账号和密码。
没有超密就停，不猜密码、不撞登录、不绕锁、不刷机。
密码只从我指定的安全存储读取，不写进命令、URL、日志、报告或 Skill。

本次只允许只读盘点，不允许保存设置、删除 WAN、导出整份配置、
开启命令入口、开始诊断、重拨、重启、切桥接模式或新增网络配置。
GET 也可能做事，不确认无副作用的入口先跳过。

先确认运营商省份、型号/固件、请求发起位置、管理地址、谁在拨号、
现有管理路径，以及是否在用固定电话和运营商电视。
没有现成授权工具就说明限制，不自行启用 MCP、安装软件或改浏览器配置。

同一密码浏览器能登录而脚本失败时，先查表单、跳转、JS Cookie 和 frame，
不要先说密码错误，不要做无限重试。

使用包内 read-only-inventory.md，逐模块、逐现有 WAN/SSID/线路记录覆盖。
源码默认值不是当前值，HTTP 200 不是登录成功，页面数不是完整性证明。
未读到的就标明未读到，敏感字段只记存在，不记原值或可猜密摘要。

最后给我：已证实事实、覆盖清单、未知项，以及每项建议的影响。
建议不是写操作授权，本次不要改任何设置。
```
