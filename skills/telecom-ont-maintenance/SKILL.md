## 一、建立后台管理路径

读取当前设备信息，确定光猫管理地址、拨号方式、路由器接口和访问路径。`192.168.1.1` 为通用管理地址示例。

- 直接连接光猫 Wi-Fi 或 LAN：从当前网络访问管理地址。
- 光猫拨号、后面接路由器：结合后级设备模式、地址和访问规则完成连接。
- 路由器拨号、光猫桥接：根据现场配置处理静态路由、管理侧地址和回复路径。

为需要调整的对象制定具体配置，完成后读取配置并验证管理访问。

使用爱快时，读取 [ikuai-cli](https://github.com/ikuaidev/ikuai-cli) 当前说明，在管理电脑安装 CLI 和配套 Skill。指定本次路由器目标和凭据来源，读取接口及现有规则，使用当前版本支持的字段完成配置。

## 二、登录后台

CGI（Common Gateway Interface，通用网关接口）用于 Web 服务器与后台程序之间的请求处理。依据当前设备实际页面提交账号和密码，保留会话并处理跳转。

### 中兴 ZXHN G7615V2 样本

- 8080 端口 `/login.cgi`，表单字段为 `username`、`psd`。
- 登录后跳转至 `/start.ghtml`，保存 SID 会话。
- 从 `/template.gch` 读取页面引用，访问对应的 `/getpage.gch` 子页面。

### ZNXT ZN-XG120 样本

- 入口先经过 80 端口页面，再向 8080 端口 `/login.cgi` 提交后台登录。
- 表单字段为 `username`、`psd`，返回结果包含 `auth_result`。
- 按网页 JavaScript 的处理，将 `ecntToken` 写入同名 Cookie。
- 加载 `/cgi-bin/content.asp` 及其引用的子页面。

读取设备当前的品牌、型号、固件和拨号方式，确认登录结果。遇到问题时，检查入口、字段、跳转、会话、来源、编码和权限状态。

## 三、开启 Telnet

中兴样本使用匹配固件的 `webFac v3` 临时维护认证，参考 [来源说明](../../THIRD_PARTY_NOTICES.md) 中的协议资料。

ZNXT 样本在后台开启 Telnet，使用设备对应的命令行和管理员凭据进入维护环境。

读取 CPU 架构、位数、字节序、可写空间、现有 SSH 服务和应用环境，为下一步选择程序及保存位置。

## 四、安装并启用 SSH

样本使用从 [Dropbear 上游](https://github.com/mkj/dropbear) 构建的 2026.94 静态程序。为当前 CPU 选择或构建程序，完成传输和完整性核对。

样本的 SAF 应用环境有自己的进程、根目录、`procd` 和 `rc.common`。从主系统维护 shell 定位当前应用管理进程、应用根目录和可写层，再进入正在运行的应用环境安装。

1. 检查现有服务和安装位置，为程序建立独立目录。
2. 配置管理端公钥认证，在设备端生成主机身份。
3. 设置服务监听地址、文件权限和启动参数。
4. 通过应用环境的原生启动机制配置服务及启动项。
5. 在管理端核对主机身份，完成 SSH 登录和命令执行验证。
6. 记录 SSH 所在环境、连接方式、程序目录和启动项，关闭本次临时开启的 Telnet。

## 五、补齐 shell 常用命令

检查当前 shell、BusyBox、命令查找路径和所需工具。中兴样本使用 BusyBox 1.37.0，构建来源见 [来源说明](../../THIRD_PARTY_NOTICES.md)；ZNXT 样本使用已有工具。

需要补充时，为对应架构准备程序，在独立目录安装工具和命令链接，配置调用路径。先用完整路径调用，再确认命令入口，验证文件查看、文字处理及状态检查功能。
